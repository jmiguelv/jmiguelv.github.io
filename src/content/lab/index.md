A sample of small experiments: tiny pages to try one idea at a time.

Each experiment is a single HTML file with its styles and scripts inlined —
no framework, no build step, no analytics. It is served exactly as written and
works in any browser. Some of these pages graduate into tools I keep using;
most stay toys.

The listing below reads the prototypes themselves at build time, so adding a
page to `public/lab/` puts it on this shelf automatically.
